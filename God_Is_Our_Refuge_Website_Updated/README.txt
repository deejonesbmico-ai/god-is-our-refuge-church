GOD IS OUR REFUGE FULL GOSPEL CHURCH WEBSITE

Files:
- index.html: homepage
- css/style.css: colors, layout, responsive design
- js/script.js: mobile navigation and current year
- images/church-logo.png: uploaded church logo

TO PREVIEW:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser (or use Live Server).

TO PUBLISH ON NETLIFY FOR FREE:
1. Open https://app.netlify.com/drop
2. Upload the extracted website folder, or ZIP it again and upload if Netlify asks for a ZIP.
3. After publishing, copy the new Netlify link and share it.

Before publishing widely, replace placeholder address, schedule, and contact information with church-approved details. The sermon cards are sample topics. The website uses Google Fonts if internet access is available; fallback fonts are included.
